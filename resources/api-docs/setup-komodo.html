Setup Komodo

Panduan menyiapkan Komodo untuk manage server, Compose stacks, container logs, container shell, monitoring resource, dan CI/CD FoodLab.

Overview Arsitektur

Struktur /opt/stacks

Komodo akan ditempatkan sebagai stack sendiri di dalam convention /opt/stacks.

/opt/stacks |-- npm |-- foodlab |-- komodo |-- monitoring `-- future-project

Arsitektur final akses Komodo:

Internet - HTTPS Nginx Proxy Manager - Docker network: proxy komodo-core:9120 - websocket komodo-periphery - Docker socket Docker Engine |-- nginx-proxy-manager |-- foodlab-web |-- foodlab-app `-- future project containers

Komodo akan diakses dari:

https://komodo.foodlabpens.com

Phase 1. DNS dan Subdomain

Buat DNS record

Type : A Name : komodo Value: IP_PUBLIC_VPS

Target akhirnya:

komodo.foodlabpens.com -> IP_PUBLIC_VPS

Phase 2. Persiapan Folder dan Network

SSH dan buat folder Komodo

ssh ubuntu@IP_VPS
sudo mkdir -p /opt/stacks/komodo sudo chown -R ubuntu:ubuntu /opt/stacks/komodo cd /opt/stacks/komodo

Pastikan network proxy sudah dibuat dari setup Docker & NPM, karena komodo-core akan di-forward oleh Nginx Proxy Manager melalui network itu.

Phase 3. Buat Environment Komodo

Generate secret

Jalankan beberapa kali dan pakai hasilnya untuk password/admin/webhook/JWT secret.

openssl rand -base64 32 openssl rand -hex 48 openssl rand -hex 48

Buat file environment:

nano compose.env

Isi file berikut, lalu ganti semua CHANGE_ME_* dengan secret yang aman.

COMPOSE_KOMODO_IMAGE_TAG=2 COMPOSE_KOMODO_BACKUPS_PATH=/opt/stacks/komodo/backups KOMODO_DATABASE_USERNAME=komodo KOMODO_DATABASE_PASSWORD=CHANGE_ME_DB_PASSWORD TZ=Asia/Jakarta KOMODO_HOST=https://komodo.foodlabpens.com KOMODO_TITLE=FoodlabKomodo KOMODO_LOCAL_AUTH=true KOMODO_INIT_ADMIN_USERNAME=admin KOMODO_INIT_ADMIN_PASSWORD=CHANGE_ME_ADMIN_PASSWORD KOMODO_FIRST_SERVER_NAME=CHANGE_ME_NAME_VPS KOMODO_WEBHOOK_SECRET=CHANGE_ME_WEBHOOK_SECRET KOMODO_JWT_SECRET=CHANGE_ME_JWT_SECRET KOMODO_JWT_TTL=1-day KOMODO_MONITORING_INTERVAL=15-sec KOMODO_RESOURCE_POLL_INTERVAL=1-hr KOMODO_DISABLE_USER_REGISTRATION=true KOMODO_ENABLE_NEW_USERS=false KOMODO_DISABLE_NON_ADMIN_CREATE=true KOMODO_TRANSPARENT_MODE=false KOMODO_OIDC_ENABLED=false KOMODO_GITHUB_OAUTH_ENABLED=false KOMODO_GOOGLE_OAUTH_ENABLED=false KOMODO_PERIPHERY_PUBLIC_KEY=file:/config/keys/periphery.pub PERIPHERY_CORE_ADDRESS=ws://core:9120 PERIPHERY_CONNECT_AS=${KOMODO_FIRST_SERVER_NAME} PERIPHERY_CORE_PUBLIC_KEYS=file:/config/keys/core.pub PERIPHERY_ROOT_DIRECTORY=/opt/stacks PERIPHERY_DISABLE_TERMINALS=false PERIPHERY_DISABLE_CONTAINER_TERMINALS=false PERIPHERY_INCLUDE_DISK_MOUNTS=/etc/hostname KOMODO_LOGGING_PRETTY=false KOMODO_PRETTY_STARTUP_CONFIG=false PERIPHERY_LOGGING_PRETTY=false PERIPHERY_PRETTY_STARTUP_CONFIG=false

Directory root yang akan dikelola Periphery:

PERIPHERY_ROOT_DIRECTORY=/opt/stacks

Phase 4. Buat Compose Komodo

File compose.yaml

nano compose.yaml

Isi:

name: komodo services: mongo: image: mongo container_name: komodo-mongo labels: komodo.skip: command: --quiet --wiredTigerCacheSizeGB 0.25 restart: unless-stopped volumes: - mongo-data:/data/db - mongo-config:/data/configdb environment: MONGO_INITDB_ROOT_USERNAME: ${KOMODO_DATABASE_USERNAME} MONGO_INITDB_ROOT_PASSWORD: ${KOMODO_DATABASE_PASSWORD} networks: - komodo-internal core: image: ghcr.io/moghtech/komodo-core:${COMPOSE_KOMODO_IMAGE_TAG:-2} container_name: komodo-core labels: komodo.skip: init: true restart: unless-stopped depends_on: - mongo env_file: - ./compose.env environment: KOMODO_DATABASE_ADDRESS: mongo:27017 KOMODO_DATABASE_USERNAME: ${KOMODO_DATABASE_USERNAME} KOMODO_DATABASE_PASSWORD: ${KOMODO_DATABASE_PASSWORD} volumes: - keys:/config/keys - ./backups:/backups expose: - "9120" networks: - komodo-internal - proxy periphery: image: ghcr.io/moghtech/komodo-periphery:${COMPOSE_KOMODO_IMAGE_TAG:-2} container_name: komodo-periphery labels: komodo.skip: init: true restart: unless-stopped depends_on: - core env_file: - ./compose.env volumes: - keys:/config/keys - /var/run/docker.sock:/var/run/docker.sock - /proc:/proc - /opt/stacks:/opt/stacks networks: - komodo-internal volumes: mongo-data: mongo-config: keys: networks: komodo-internal: driver: bridge proxy: external: true

Catatan penting: hanya komodo-core yang perlu diexpose ke network proxy.

expose: - "9120"

Phase 5. Jalankan Komodo

Pull, start, dan cek logs

cd /opt/stacks/komodo

Pull image:

docker compose --env-file compose.env pull

Start:

docker compose --env-file compose.env up -d

Cek container:

docker compose --env-file compose.env ps

Cek logs:

docker logs --tail=100 komodo-core docker logs --tail=100 komodo-periphery docker logs --tail=100 komodo-mongo

Expected:

komodo-core running komodo-periphery running komodo-mongo running

Phase 6. Setup Nginx Proxy Manager

Proxy Host Komodo

Masuk ke NPM admin panel:

http://IP_PUBLIC_VPS:81

Buat Proxy Host baru:

Domain Names: komodo.foodlabpens.com Scheme: http Forward Hostname / IP: komodo-core Forward Port: 9120 Websockets Support: ON Block Common Exploits: ON

SSL tab:

Request a new SSL Certificate Force SSL: ON HTTP/2 Support: ON HSTS: OFF dulu

Websockets Support wajib ON. Komunikasi Komodo Core dan Periphery menggunakan websocket. Reverse proxy juga perlu meneruskan host header ke domain Komodo Core.

Setelah itu buka:

https://komodo.foodlabpens.com

Login:

Username: admin Password: sesuai KOMODO_INIT_ADMIN_PASSWORD

Setelah berhasil login, simpan password di password manager.

Phase 7. Validasi Periphery dan Server Lokal

Cek server di dashboard Komodo

Di dashboard Komodo, cari server:

NAMA_VPS

Status yang diharapkan:

OK / Connected

Validasi dari server:

docker logs --tail=200 komodo-periphery

Cek apakah Komodo bisa melihat container existing:

nginx-proxy-manager foodlab-web foodlab-app komodo-core komodo-periphery komodo-mongo
