CI/CD Komodo

Panduan membuat deploy otomatis FoodLab dari push branch staging melalui GitHub Webhook, Komodo Action, dan script deploy di server.

Target Flow

Alur deployment staging

Developer push ke branch staging - GitHub Webhook - Komodo Action / Procedure - Run /opt/stacks/foodlab/deploy-staging.sh - git pull staging - docker compose up -d --build foodlab-app foodlab-web - composer install - artisan optimize/migrate/cache - restart container - health check https://foodlabpens.com

Komodo mendukung webhook dari Git provider. Untuk Action atau Procedure, webhook execution bisa diarahkan ke nama branch seperti /staging, sehingga push branch lain tidak menjalankan deploy staging.

Step 1. Import FoodLab sebagai Stack

Import existing compose project

Di Komodo, buka:

Resources -> Stacks -> New Stack

Isi konfigurasi stack:

Name: foodlab Server: server-prod / nama server Komodo kamu Source: Files on host Run directory: /opt/stacks/foodlab Compose files: compose.yaml Project name: foodlab

Struktur folder yang dipakai:

/opt/stacks/foodlab |-- compose.yaml |-- deploy-staging.sh |-- docker/ `-- src/

Setelah dibuat, klik Refresh dulu supaya Komodo membaca status container existing. Setelah aman, test Deploy dari UI.

Step 2. Rapikan Deploy Script FoodLab

File /opt/stacks/foodlab/deploy-staging.sh

Simpan script berikut sebagai /opt/stacks/foodlab/deploy-staging.sh.

#!/usr/bin/env bash set -Eeuo pipefail APP_DIR="/opt/stacks/foodlab" SRC_DIR="/opt/stacks/foodlab/src" BRANCH="staging" DOMAIN="https://foodlabpens.com" LOCK_FILE="/tmp/foodlab-staging-deploy.lock" exec 9>"$LOCK_FILE" if ! flock -n 9; then echo "==> Another Foodlab staging deploy is already running" exit 1 fi trap 'echo "==> Deploy failed at line $LINENO"; date' ERR echo "==> Starting Foodlab staging deploy" date echo "==> Current directory check" cd "$SRC_DIR" echo "==> Mark host git directory as safe" git config --global --add safe.directory "$SRC_DIR" echo "==> Fetch latest code" git fetch origin "$BRANCH" echo "==> Checkout branch" git checkout "$BRANCH" echo "==> Pull latest commit" git pull --ff-only origin "$BRANCH" echo "==> Latest commit" git log -1 --oneline echo "==> Ensure containers are running" cd "$APP_DIR" docker compose up -d --build foodlab-app foodlab-web echo "==> Mark container git directory as safe" docker exec foodlab-app git config --global --add safe.directory /var/www/html || true echo "==> Composer install" docker exec foodlab-app composer install \ --no-dev \ --prefer-dist \ --no-interaction \ --optimize-autoloader echo "==> Laravel clear old cache" docker exec foodlab-app php artisan optimize:clear echo "==> Laravel migrate" docker exec foodlab-app php artisan migrate --force echo "==> Laravel cache config" docker exec foodlab-app php artisan config:cache # Disabled because Foodlab currently has duplicate route name verification.verify. # Enable again only after duplicate route name is fixed. # docker exec foodlab-app php artisan route:cache echo "==> Laravel cache views" docker exec foodlab-app php artisan view:cache echo "==> Fix Laravel permissions" docker exec foodlab-app chown -R www-data:www-data storage bootstrap/cache docker exec foodlab-app chmod -R ug+rwx storage bootstrap/cache echo "==> Restart app containers" docker compose restart foodlab-app foodlab-web echo "==> Container status" docker compose ps echo "==> Health check" curl -fsS --retry 5 --retry-delay 2 "$DOMAIN" > /dev/null echo "==> Deploy finished successfully" date

Pastikan executable:

chmod +x /opt/stacks/foodlab/deploy-staging.sh

Step 3. Buat Komodo Action

Action untuk menjalankan script

Di Komodo, buka:

Resources -> Actions -> New Action

Isi metadata:

Name: foodlab-deploy-staging Description: Deploy Foodlab from staging branch using existing deploy script

Isi script Action TypeScript:

await komodo.execute_server_terminal( { server: "server-prod", command: "bash -lc '/opt/stacks/foodlab/deploy-staging.sh'", init: { command: "bash" }, }, { onLine: (line) => console.log(line), onFinish: (code) => console.log("Exit code:", code), } );

Ganti server-prod dengan nama Server resource kamu di Komodo. Setelah Action dibuat, klik Run manual sekali dari UI Komodo. Kalau sukses, script siap dipanggil webhook.

Step 4. Buat Webhook GitHub ke Komodo

Webhook branch staging

Di Komodo, buka:

Action foodlab-deploy-staging -> Config -> Webhooks

Copy webhook URL. Bentuknya kurang lebih:

https://KOMODO_DOMAIN/listener/github/action/foodlab-deploy-staging/staging

Di GitHub repo FoodLab, buka:

Repository -> Settings -> Webhooks -> Add webhook

Isi:

Payload URL: URL webhook dari Komodo Content type: application/json Secret: KOMODO_WEBHOOK_SECRET Events: Just the push event Active: checked

Dengan URL branch /staging, push ke branch lain tidak akan menjalankan deploy staging.

Step 5. Test End-to-End

Trigger dari local

git checkout staging git commit --allow-empty -m "test: komodo staging deploy" git push origin staging

Lalu cek di Komodo:

Action foodlab-deploy-staging -> Updates / Logs

Expected log:

==> Starting Foodlab staging deploy ==> Fetch latest code ==> Pull latest commit ==> Ensure containers are running ==> Composer install ==> Laravel migrate ==> Laravel cache config ==> Laravel cache views ==> Restart app containers ==> Health check ==> Deploy finished successfully

Kalau health check gagal, cek:

docker compose ps docker logs --tail=100 foodlab-web docker logs --tail=100 foodlab-app docker exec foodlab-app php artisan migrate:status
