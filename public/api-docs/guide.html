2. Docker Image Implementations

Dockerfile Multi-Arch Architecture

Addressing Buster EOL repositories manually during the container configuration layer:

FROM php:7.4-fpm-buster # Gunakan repositori archive Debian (karena Buster EOL) RUN printf "deb [trusted=yes] http://archive.debian.org/debian buster main contrib non-free\n" > /etc/apt/sources.list \ && printf "deb [trusted=yes] http://archive.debian.org/debian-security buster/updates main contrib non-free\n" >> /etc/apt/sources.list \ && apt-get -o Acquire::Check-Valid-Until=false update -y \ && apt-get install -y --no-install-recommends zip unzip git curl libonig-dev libpng-dev libpq-dev default-mysql-client \ && docker-php-ext-install zip mbstring gd pdo pdo_mysql pgsql mysqli # Install Composer RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/bin --filename=composer # Work directory & Unprivileged Execution Setup WORKDIR /var/www/html COPY . /var/www/html RUN useradd -u 1000 -ms /bin/bash -g www-data masbro && chown -R www-data:www-data /var/www/html USER masbro # Install Laravel Dependencies RUN composer install --no-interaction --no-ansi --no-scripts --no-progress || true EXPOSE 9000 CMD ["php-fpm"]

Troubleshooting Container Connectivity

When watchtower containers lose ping connectivity in constrained networks (like Telkom University local nets), hardcode the APK endpoints:

root@ubisma:~/ubisma-app/foodlab# docker run --rm -it --network foodlab_ubisma_network alpine /bin/sh # Inject localized mirror resolutions echo "http://mirror.telkomuniversity.ac.id/alpine/v3.22/main" > /etc/apk/repositories echo "http://mirror.telkomuniversity.ac.id/alpine/v3.22/community" >> /etc/apk/repositories

3. Elasticsearch (ELK Stack Analysis)

JVM Heap & Base Installations (Elasticsearch 8.x)

Crucial to system performance is capping the RAM. Do not let JVM run rampant by defining explicit bounds in /etc/elasticsearch/jvm.options.d/heap.options:

-Xms16g -Xmx16g

Activate Elasticsearch by pulling via the GPG signing keys and adjusting default elasticsearch.yml.

sudo /usr/share/elasticsearch/bin/elasticsearch-setup-passwords interactive

Kibana Instantiation

Establish Kibana routing onto port 5601 through the host node using /etc/kibana/kibana.yml configuration overrides.

server.port: 5601 server.host: "0.0.0.0" elasticsearch.hosts: ["http://127.0.0.1:9200"] elasticsearch.username: "kibana_system" # elasticsearch.password: "YOUR_PASSWORD"

Filebeat Mapping to Logstash Pipeline

Enable the JSON parsing pipeline internally logic with Logstash /etc/logstash/conf.d/10-beats.conf ensuring standard grok logic passes freely. Point Filebeat output node to port 5044:

filebeat.inputs: - type: log enabled: true paths: - /var/www/foodlab/storage/logs/laravel.json.log json.keys_under_root: true output.logstash: hosts: ["localhost:5044"]

Refining Laravel Application Logs to Pure JSON

Eliminate regex Grok overhead by re-routing Laravel's native logging protocol explicitly utilizing Monolog’s Custom Formatter into standard JSON notation.

// Update config/logging.php 'channels' => [ 'json' => [ 'driver' => 'single', 'path' => storage_path('logs/laravel.json.log'), 'level' => env('LOG_LEVEL', 'debug'), 'tap' => [App\Logging\CustomizeFormatter::class], ], ]

Implement the Custom Tap class logic in app/Logging/CustomizeFormatter.php passing a Monolog\Formatter\JsonFormatter::BATCH_MODE_NEWLINES.
