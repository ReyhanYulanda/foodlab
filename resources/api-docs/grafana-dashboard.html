Grafana Dashboard

Panduan membuat datasource Prometheus dan Loki, import dashboard server/container metrics, serta membuat dashboard custom untuk FoodLab logs dan overview.

1. Login Grafana

Buka domain reverse proxy

https://grafana.dk.foodlabpens.com

Login dengan akun admin Grafana:

Username: admin Password: password di GF_SECURITY_ADMIN_PASSWORD

2. Tambahkan Datasource Prometheus

Datasource metrics

Masuk ke menu:

Connections -> Data sources -> Add data source -> Prometheus

Isi konfigurasi:

Name: Prometheus Prometheus server URL: http://prometheus:9090

Klik:

Save & test

Harus muncul sukses. Kalau gagal, test dari server:

docker exec -it monitoring-grafana wget -qO- http://prometheus:9090/-/ready

3. Tambahkan Datasource Loki

Datasource logs

Masuk ke menu:

Connections -> Data sources -> Add data source -> Loki

Isi konfigurasi:

Name: Loki URL: http://monitoring-loki:3100

Klik:

Save & test

Karena Loki sudah ready di stack log management, datasource harus sukses. Cek dari Grafana ke Loki kalau perlu:

docker exec -it monitoring-grafana wget -qO- http://monitoring-loki:3100/ready

4. Buat Folder Dashboard

Folder FoodLab Monitoring

Supaya dashboard rapi, buat folder baru:

Dashboards -> New -> New folder

Nama folder:

Foodlab Monitoring

Nanti semua dashboard masuk folder ini.

5. Import Dashboard Server Metrics

Node Exporter Full

Dashboard ini untuk CPU, RAM, disk, dan network host/server.

Dashboards -> New -> Import

Isi dashboard ID:

1860

Klik Load, lalu set:

Folder: Foodlab Monitoring Prometheus datasource: Prometheus

Klik:

Import

Setelah import, kalau variable job muncul, pilih:

node-exporter

Prometheus config kita memakai job name:

job_name: "node-exporter"

6. Import Dashboard Docker Metrics

cAdvisor Docker/container metrics

Dashboard ini untuk container seperti foodlab-app, foodlab-web, nginx-proxy-manager, monitoring-grafana, monitoring-loki, dan monitoring-alloy.

Dashboards -> New -> Import

Coba dashboard ID ini dulu:

19908

Set:

Folder: Foodlab Monitoring Prometheus datasource: Prometheus

Klik:

Import

Kalau panel kosong, coba alternatif yang juga cocok untuk cAdvisor:

19792

7. Buat Dashboard Custom FoodLab Logs

Mulai dashboard logs

Dashboard community kadang label-nya tidak cocok dengan setup Alloy. Karena Alloy mengirim label berikut, lebih aman buat dashboard custom:

app="foodlab" service="laravel" server="singapore" level="ERROR" / INFO / WARNING / ...

Masuk ke:

Dashboards -> New -> New dashboard Add visualization Datasource: Loki

Panel FoodLab Logs

Panel 1: Laravel Logs Stream

Panel type: Logs Query: {app="foodlab"} Title: Foodlab Laravel Logs

Panel 2: Laravel Error Logs

Panel type: Logs Query: {app="foodlab", level="ERROR"} Title: Foodlab Error Logs

Panel 3: Error count last 5 minutes

Panel type: Stat Query: sum(count_over_time({app="foodlab", level="ERROR"}[5m])) Title: Laravel Errors - Last 5m

Panel 4: SQLSTATE / database errors

Panel type: Logs Query: {app="foodlab"} |= "SQLSTATE" Title: Database / SQLSTATE Errors

Panel 5: NPM access logs

Panel type: Logs Query: {app="npm", type="access"} Title: Nginx Proxy Manager Access Logs

Panel 6: NPM error logs

Panel type: Logs Query: {app="npm", type="error"} Title: Nginx Proxy Manager Error Logs

8. Save FoodLab Logs Dashboard

Simpan dashboard logs

Klik kanan atas:

Save dashboard

Isi:

Title: Foodlab Logs Folder: Foodlab Monitoring

Klik:

Save

9. Buat Dashboard Custom FoodLab Overview

Mulai dashboard overview

Dashboards -> New -> New dashboard

Tambahkan panel-panel berikut.

Panel logs overview

Panel 1: Total Laravel logs per minute

Datasource: Loki Panel type: Time series Query: sum(rate({app="foodlab"}[1m])) Title: Laravel Log Rate

Panel 2: Error rate

Datasource: Loki Panel type: Time series Query: sum(rate({app="foodlab", level="ERROR"}[1m])) Title: Laravel Error Rate

Panel 3: Error count by level

Datasource: Loki Panel type: Bar chart Query: sum by (level) (count_over_time({app="foodlab"}[15m])) Title: Logs by Level - Last 15m

Panel infrastructure overview

Panel 4: Container CPU

Datasource: Prometheus Panel type: Time series Query: sum by (name) (rate(container_cpu_usage_seconds_total{name!=""}[5m])) Title: Container CPU Usage

Panel 5: Container memory

Datasource: Prometheus Panel type: Time series Query: container_memory_usage_bytes{name!=""} Title: Container Memory Usage

Panel 6: Server memory usage

Datasource: Prometheus Panel type: Gauge Query: (1 - (node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes)) * 100 Title: Server Memory Usage %

Panel 7: Server CPU usage

Datasource: Prometheus Panel type: Gauge Query: 100 - (avg(rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100) Title: Server CPU Usage %

Simpan dashboard overview

Title: Foodlab Overview Folder: Foodlab Monitoring

10. Set Dashboard sebagai Homepage

Default preference Grafana

Masuk ke:

Administration -> General -> Default preferences

Cari:

Home dashboard

Pilih:

Foodlab Overview

Lalu klik Save. Kalau menu berbeda, buka dashboard Foodlab Overview dan klik icon star agar masuk favorites.

11. Test Data Muncul

Generate log dan cek dashboard

Di server, generate log test:

printf "[%s] production.ERROR: Grafana dashboard test {\"source\":\"manual-dashboard-test\"}\n" "$(date '+%Y-%m-%d %H:%M:%S')" | sudo tee -a /opt/stacks/foodlab/src/storage/logs/laravel.log > /dev/null

Tunggu 10 detik. Di dashboard Foodlab Logs, panel berikut harus muncul:

Foodlab Error Logs Laravel Errors - Last 5m

Kalau belum muncul, cek langsung dari server:

curl -G -s "http://127.0.0.1:3100/loki/api/v1/query" \ --data-urlencode 'query={app="foodlab"}' | head -c 1500
