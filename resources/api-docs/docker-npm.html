Docker & Nginx Proxy Manager

Step-by-step deployment guide untuk menyiapkan Docker, Nginx Proxy Manager, MySQL host service, project FoodLab, reverse proxy, SSL, dan deploy script di server.

0. Akses Server & DNS

Security List

Di instance VPS, buka port berikut saja. Port NPM admin sebaiknya dibatasi ke IP pribadi.

22/tcp SSH 80/tcp HTTP 443/tcp HTTPS 81/tcp NPM admin, idealnya batasi ke IP kamu saja

Jangan buka 3306 ke publik. MySQL boleh diakses container Docker melalui network internal, tapi tidak untuk public internet.

Update DNS domain ke public IP server baru.

foodlabpens.com A -> NEW_PUBLIC_IP www.foodlabpens.com A -> NEW_PUBLIC_IP

1. Install Package Dasar + Docker

Install dependency server dan Docker Engine

Jalankan command berikut di VPS. Docker official apt repository mendukung Ubuntu 22.04/24.04.

sudo apt update sudo apt install -y ca-certificates curl git unzip zip nano htop mysql-server iptables-persistent # Remove conflicting Docker packages if any for pkg in docker.io docker-doc docker-compose docker-compose-v2 podman-docker containerd runc; do sudo apt remove -y "$pkg" || true done # Docker official apt repo sudo install -m 0755 -d /etc/apt/keyrings sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc sudo chmod a+r /etc/apt/keyrings/docker.asc sudo bash -lc 'cat > /etc/apt/sources.list.d/docker.sources <<EOF Types: deb URIs: https://download.docker.com/linux/ubuntu Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}") Components: stable Architectures: $(dpkg --print-architecture) Signed-By: /etc/apt/keyrings/docker.asc EOF' sudo apt update sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin sudo systemctl enable --now docker sudo usermod -aG docker ubuntu docker --version docker compose version

Logout-login ulang SSH setelah usermod, atau jalankan sementara:

newgrp docker

2. Buat Struktur /opt/stacks

Folder convention dan Docker network

Gunakan rule satu project satu folder: /opt/stacks/{project}. Contoh: npm, foodlab, dan nanti bisa ditambah monitoring.

sudo mkdir -p /opt/stacks/{npm,foodlab} sudo chown -R ubuntu:ubuntu /opt/stacks cd /opt/stacks docker network create proxy || true

Struktur target:

/opt/stacks |-- npm | `-- compose.yaml `-- foodlab |-- compose.yaml |-- deploy-staging.sh |-- docker | |-- nginx | | `-- default.conf | `-- php | `-- Dockerfile `-- src

3. Setup Nginx Proxy Manager

Buat compose NPM

NPM memakai image jc21/nginx-proxy-manager:latest, expose port 80, 443, dan 81, lalu join ke external network proxy.

mkdir -p /opt/stacks/npm cd /opt/stacks/npm cat > compose.yaml <<'YAML' services: npm: image: jc21/nginx-proxy-manager:latest container_name: nginx-proxy-manager restart: unless-stopped ports: - "80:80" - "443:443" - "81:81" environment: TZ: Asia/Jakarta DISABLE_IPV6: "true" volumes: - ./data:/data - ./letsencrypt:/etc/letsencrypt networks: - proxy networks: proxy: external: true YAML docker compose up -d docker ps

Buka dashboard NPM, lalu langsung ganti email dan password admin setelah login pertama.

http://NEW_PUBLIC_IP:81

4. Setup MySQL Host untuk FoodLab

Konfigurasi MySQL host service

FoodLab menggunakan MySQL host service, bukan container DB. Database yang dipakai adalah foodlab, user app foodlab, dan container connect via host pattern foodlab@172.%.

sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf

Pastikan bind address:

bind-address = 0.0.0.0

Restart dan cek service:

sudo systemctl enable --now mysql sudo systemctl restart mysql sudo ss -tulpn | grep 3306

Buat database dan user aplikasi:

sudo mysql
CREATE DATABASE IF NOT EXISTS foodlab CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; CREATE USER IF NOT EXISTS 'foodlab'@'172.%' IDENTIFIED BY 'CHANGE_ME_DB_PASSWORD'; GRANT ALL PRIVILEGES ON foodlab.* TO 'foodlab'@'172.%'; CREATE USER IF NOT EXISTS 'foodlab'@'localhost' IDENTIFIED BY 'CHANGE_ME_DB_PASSWORD'; GRANT ALL PRIVILEGES ON foodlab.* TO 'foodlab'@'localhost'; CREATE USER IF NOT EXISTS 'foodlab'@'127.0.0.1' IDENTIFIED BY 'CHANGE_ME_DB_PASSWORD'; GRANT ALL PRIVILEGES ON foodlab.* TO 'foodlab'@'127.0.0.1'; FLUSH PRIVILEGES; EXIT;

Allow Docker subnet ke MySQL host. Ini menghindari error SQLSTATE[HY000] [2002] No route to host.

sudo iptables -I INPUT 1 -s 172.16.0.0/12 -p tcp --dport 3306 -j ACCEPT sudo netfilter-persistent save sudo systemctl enable netfilter-persistent

5. Setup Folder FoodLab

Buat folder dan clone repository

mkdir -p /opt/stacks/foodlab/docker/nginx mkdir -p /opt/stacks/foodlab/docker/php cd /opt/stacks/foodlab

Clone branch staging dari repository FoodLab.

git clone -b staging https://github.com/foodlabdev/foodlab.git src

Kalau repository private, gunakan SSH deploy key:

git clone -b staging git@github.com:foodlabdev/foodlab.git src

6. Compose, PHP Dockerfile, dan Nginx Internal

Buat compose.yaml FoodLab

foodlab-app adalah PHP-FPM Laravel, foodlab-web adalah nginx internal. Hanya foodlab-web yang join network proxy.

cd /opt/stacks/foodlab cat > compose.yaml <<'YAML' services: foodlab-app: build: context: . dockerfile: docker/php/Dockerfile container_name: foodlab-app restart: unless-stopped working_dir: /var/www/html env_file: - ./src/.env volumes: - ./src:/var/www/html extra_hosts: - "host.docker.internal:host-gateway" networks: - foodlab-internal foodlab-web: image: nginx:1.27-alpine container_name: foodlab-web restart: unless-stopped depends_on: - foodlab-app volumes: - ./src:/var/www/html:ro - ./docker/nginx/default.conf:/etc/nginx/conf.d/default.conf:ro expose: - "80" networks: - foodlab-internal - proxy networks: foodlab-internal: driver: bridge proxy: external: true YAML

Buat PHP Dockerfile

FoodLab memakai base php:7.4-fpm-bullseye dan extension Laravel/MySQL seperti pdo_mysql, mbstring, gd, zip, dan intl.

cat > /opt/stacks/foodlab/docker/php/Dockerfile <<'DOCKERFILE' FROM php:7.4-fpm-bullseye RUN apt-get update && apt-get install -y --no-install-recommends \ git \ curl \ unzip \ zip \ libpng-dev \ libjpeg-dev \ libfreetype6-dev \ libzip-dev \ libonig-dev \ libxml2-dev \ libicu-dev \ default-mysql-client \ && docker-php-ext-configure gd --with-freetype --with-jpeg \ && docker-php-ext-install \ pdo_mysql \ mbstring \ exif \ pcntl \ bcmath \ gd \ zip \ intl \ && apt-get clean \ && rm -rf /var/lib/apt/lists/* COPY --from=composer:2 /usr/bin/composer /usr/bin/composer WORKDIR /var/www/html RUN usermod -u 1000 www-data && groupmod -g 1000 www-data CMD ["php-fpm"] DOCKERFILE

Buat nginx internal config FoodLab

Nginx internal Laravel harus mengarah ke /var/www/html/public, memakai try_files, lalu fastcgi_pass foodlab-app:9000.

cat > /opt/stacks/foodlab/docker/nginx/default.conf <<'NGINX' server { listen 80; server_name _; root /var/www/html/public; index index.php index.html; access_log /var/log/nginx/access.log; error_log /var/log/nginx/error.log; client_max_body_size 64M; location / { try_files $uri $uri/ /index.php?$query_string; } location ~ \.php$ { try_files $uri =404; fastcgi_split_path_info ^(.+\.php)(/.+)$; fastcgi_pass foodlab-app:9000; fastcgi_index index.php; include fastcgi_params; fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name; fastcgi_param DOCUMENT_ROOT $realpath_root; } location ~ /\.(?!well-known).* { deny all; } } NGINX

7. Environment dan Start FoodLab

Buat .env FoodLab

cd /opt/stacks/foodlab/src cp .env.example .env || true nano .env

Minimal pastikan konfigurasi berikut:

APP_ENV=production APP_DEBUG=false APP_URL=https://dk.foodlabpens.com DB_CONNECTION=mysql DB_HOST=host.docker.internal DB_PORT=3306 DB_DATABASE=foodlab DB_USERNAME=foodlab DB_PASSWORD=CHANGE_ME_DB_PASSWORD SESSION_SECURE_COOKIE=true

Kalau DB gagal, cek gateway network FoodLab:

docker network inspect foodlab_foodlab-internal | grep Gateway

Build, start container, dan install dependency Laravel

cd /opt/stacks/foodlab docker compose build docker compose up -d docker compose ps docker logs --tail=100 foodlab-app docker logs --tail=100 foodlab-web
docker exec -it foodlab-app sh -lc 'cd /var/www/html && git config --global --add safe.directory /var/www/html' docker exec -it foodlab-app sh -lc 'cd /var/www/html && composer install --no-dev --optimize-autoloader' docker exec -it foodlab-app sh -lc 'cd /var/www/html && php artisan key:generate --force' docker exec -it foodlab-app sh -lc 'cd /var/www/html && php artisan migrate --force' docker exec -it foodlab-app sh -lc 'cd /var/www/html && php artisan optimize:clear' docker exec -it foodlab-app sh -lc 'cd /var/www/html && php artisan config:cache' docker exec -it foodlab-app sh -lc 'cd /var/www/html && php artisan view:cache' docker exec -it foodlab-app sh -lc 'cd /var/www/html && chown -R www-data:www-data storage bootstrap/cache' docker restart foodlab-app foodlab-web

Jangan jalankan php artisan route:cache dulu. Deploy lama pernah gagal karena duplicate route name verification.verify. Deploy sukses melewati route cache dan hanya cache config/views.

9. Laravel TrustProxies

Trust reverse proxy

Karena FoodLab berada di belakang NPM, Laravel harus trust reverse proxy. Ini mencegah form/action masih generate http:// saat user membuka HTTPS.

nano /opt/stacks/foodlab/src/app/Http/Middleware/TrustProxies.php

Isi ideal:

<?php namespace App\Http\Middleware; use Illuminate\Http\Middleware\TrustProxies as Middleware; use Illuminate\Http\Request; class TrustProxies extends Middleware { protected $proxies = '*'; protected $headers = Request::HEADER_X_FORWARDED_FOR | Request::HEADER_X_FORWARDED_HOST | Request::HEADER_X_FORWARDED_PORT | Request::HEADER_X_FORWARDED_PROTO; }

Lalu clear cache dan restart:

docker exec -it foodlab-app php artisan optimize:clear docker exec -it foodlab-app php artisan config:cache docker restart foodlab-app foodlab-web

10. Deploy Script

Buat deploy-staging.sh

cat > /opt/stacks/foodlab/deploy-staging.sh <<'BASH' #!/usr/bin/env bash set -e echo "==> Starting FoodLab staging deploy" date echo "==> Fetch latest code" cd /opt/stacks/foodlab/src git config --global --add safe.directory /opt/stacks/foodlab/src git fetch origin staging git checkout staging git pull origin staging git log -1 --oneline echo "==> Build and start containers" cd /opt/stacks/foodlab docker compose up -d --build echo "==> Composer install" docker compose exec -T foodlab-app sh -lc 'cd /var/www/html && git config --global --add safe.directory /var/www/html' docker compose exec -T foodlab-app sh -lc 'cd /var/www/html && composer install --no-dev --optimize-autoloader' echo "==> Laravel cache and migrate" docker compose exec -T foodlab-app sh -lc 'cd /var/www/html && php artisan optimize:clear' docker compose exec -T foodlab-app sh -lc 'cd /var/www/html && php artisan migrate --force' docker compose exec -T foodlab-app sh -lc 'cd /var/www/html && php artisan config:cache' docker compose exec -T foodlab-app sh -lc 'cd /var/www/html && php artisan view:cache' # NOTE: # Jangan route:cache dulu karena FoodLab pernah gagal: # duplicate route name verification.verify. echo "==> Fix permissions" docker compose exec -T foodlab-app sh -lc 'cd /var/www/html && chown -R www-data:www-data storage bootstrap/cache' echo "==> Restart app containers" docker compose restart foodlab-app foodlab-web echo "==> Container status" docker compose ps echo "==> Deploy finished successfully" date BASH chmod +x /opt/stacks/foodlab/deploy-staging.sh

Run deploy:

/opt/stacks/foodlab/deploy-staging.sh

12. Urutan Paling Aman

Checklist eksekusi

  1. Allow firewall port 22/80/443/81.
  2. Update DNS ke IP Singapore.
  3. Install Docker.
  4. Buat /opt/stacks dan Docker network proxy.
  5. Start NPM.
  6. Setup MySQL host, database foodlab, dan user foodlab.
  7. Clone FoodLab ke /opt/stacks/foodlab/src.
  8. Buat compose.yaml, Dockerfile, dan nginx default.conf.
  9. Buat .env.
  10. Jalankan docker compose up -d --build.
  11. Jalankan composer install, artisan migrate, dan cache config/view.
  12. Setup Proxy Host NPM ke foodlab-web:80.
  13. Test HTTPS.
  14. Simpan dan gunakan deploy-staging.sh.

13. Akses Root MySQL untuk Admin

Opsional: set password root untuk SSH tunnel atau DBeaver

Jalankan di VPS, bukan di DBeaver:

sudo mysql

Di prompt MySQL:

ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'CHANGE_ME_ROOT_PASSWORD'; FLUSH PRIVILEGES; EXIT;

Test dari server:

mysql -u root -p -h 127.0.0.1

Konfigurasi DBeaver via SSH tunnel:

Host: 127.0.0.1 Port: 3306 Database: foodlab Username: root Password: CHANGE_ME_ROOT_PASSWORD

Jangan pakai root untuk Laravel/FoodLab .env. Root hanya untuk admin via SSH tunnel atau DBeaver. Untuk aplikasi tetap pakai user foodlab.

Kalau command mysql_native_password error, pakai alternatif:

ALTER USER 'root'@'localhost' IDENTIFIED BY 'CHANGE_ME_ROOT_PASSWORD'; FLUSH PRIVILEGES; EXIT;

Cek user yang ada:

SELECT user, host, plugin FROM mysql.user;
