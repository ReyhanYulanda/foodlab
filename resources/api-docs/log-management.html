Log Management

Step-by-step setup monitoring dan log management FoodLab menggunakan Prometheus, Grafana, node-exporter, cAdvisor, Loki, Alloy, dan Nginx Proxy Manager.

1. Buat Network Monitoring dan Proxy

Network eksternal Docker

Stack monitoring memakai network external monitoring. Grafana juga perlu join network proxy supaya bisa di-forward dari Nginx Proxy Manager.

networks: monitoring: external: true

Cek network yang sudah ada:

docker network ls | grep -E 'monitoring|proxy'

Harus ada:

monitoring proxy

Kalau belum ada, buat network:

docker network create proxy || true docker network rm monitoring 2>/dev/null || true docker network create monitoring

2. Buat Monitoring Compose

File /opt/stacks/monitoring/compose.yaml

Stack ini berisi Prometheus, Grafana, node-exporter, dan cAdvisor. Ganti password Grafana sebelum dijalankan.

mkdir -p /opt/stacks/monitoring cat > /opt/stacks/monitoring/compose.yaml <<'YAML' services: prometheus: image: prom/prometheus:latest container_name: monitoring-prometheus restart: unless-stopped command: - "--config.file=/etc/prometheus/prometheus.yml" - "--storage.tsdb.path=/prometheus" - "--storage.tsdb.retention.time=30d" volumes: - ./prometheus/prometheus.yml:/etc/prometheus/prometheus.yml:ro - prometheus-data:/prometheus expose: - "9090" networks: - monitoring grafana: image: grafana/grafana:latest container_name: monitoring-grafana restart: unless-stopped environment: GF_SECURITY_ADMIN_USER: admin GF_SECURITY_ADMIN_PASSWORD: "CHANGE_ME_GRAFANA_PASSWORD" GF_USERS_ALLOW_SIGN_UP: "false" GF_SERVER_ROOT_URL: "https://grafana.dk.foodlabpens.com" GF_SERVER_DOMAIN: "grafana.dk.foodlabpens.com" volumes: - grafana-data:/var/lib/grafana expose: - "3000" networks: - monitoring - proxy depends_on: - prometheus node-exporter: image: prom/node-exporter:latest container_name: monitoring-node-exporter restart: unless-stopped command: - "--path.rootfs=/host" pid: host volumes: - /:/host:ro,rslave expose: - "9100" networks: - monitoring cadvisor: image: gcr.io/cadvisor/cadvisor:latest container_name: monitoring-cadvisor restart: unless-stopped privileged: true devices: - /dev/kmsg:/dev/kmsg volumes: - /:/rootfs:ro - /var/run:/var/run:ro - /sys:/sys:ro - /var/lib/docker/:/var/lib/docker:ro - /dev/disk/:/dev/disk:ro expose: - "8080" networks: - monitoring volumes: prometheus-data: grafana-data: networks: monitoring: external: true proxy: external: true YAML

Ganti password Grafana:

nano /opt/stacks/monitoring/compose.yaml

3. Buat Prometheus Config

Scrape Prometheus, node-exporter, dan cAdvisor

mkdir -p /opt/stacks/monitoring/prometheus cat > /opt/stacks/monitoring/prometheus/prometheus.yml <<'YAML' global: scrape_interval: 15s evaluation_interval: 15s scrape_configs: - job_name: "prometheus" static_configs: - targets: - "prometheus:9090" - job_name: "node-exporter" static_configs: - targets: - "node-exporter:9100" - job_name: "cadvisor" static_configs: - targets: - "cadvisor:8080" YAML

4. Start Monitoring

Jalankan stack metrics

cd /opt/stacks/monitoring docker compose up -d docker compose ps

Test readiness dan metrics endpoint dari dalam container Prometheus:

docker exec -it monitoring-prometheus wget -qO- http://prometheus:9090/-/ready docker exec -it monitoring-prometheus wget -qO- http://node-exporter:9100/metrics | head docker exec -it monitoring-prometheus wget -qO- http://cadvisor:8080/metrics | head

5. Buat Observability Compose

File /opt/stacks/observability/compose.yaml

Stack observability berisi Loki sebagai log store dan Alloy sebagai log collector. Alloy membaca log Laravel FoodLab dan log NPM.

mkdir -p /opt/stacks/observability/{loki,alloy} cat > /opt/stacks/observability/compose.yaml <<'YAML' services: monitoring-loki: image: grafana/loki:3.7.0 container_name: monitoring-loki restart: unless-stopped command: -config.file=/etc/loki/loki-config.yaml ports: - "127.0.0.1:3100:3100" volumes: - ./loki/loki-config.yaml:/etc/loki/loki-config.yaml:ro - ./loki/data:/loki networks: - monitoring monitoring-alloy: image: grafana/alloy:latest container_name: monitoring-alloy restart: unless-stopped user: "0:0" command: - run - --server.http.listen-addr=0.0.0.0:12345 - --storage.path=/var/lib/alloy/data - /etc/alloy/config.alloy volumes: - ./alloy/config.alloy:/etc/alloy/config.alloy:ro - ./alloy/data:/var/lib/alloy/data - /opt/stacks/foodlab/src/storage/logs:/logs/foodlab/laravel:ro - /opt/stacks/npm/data/logs:/logs/npm:ro depends_on: - monitoring-loki networks: - monitoring networks: monitoring: external: true YAML

6. Buat Loki Config

File loki-config.yaml

Konfigurasi ini memakai filesystem storage, schema TSDB v13, dan retention 720 jam.

cat > /opt/stacks/observability/loki/loki-config.yaml <<'YAML' auth_enabled: false server: http_listen_port: 3100 grpc_listen_port: 9096 log_level: info common: instance_addr: 127.0.0.1 path_prefix: /loki storage: filesystem: chunks_directory: /loki/chunks rules_directory: /loki/rules replication_factor: 1 ring: kvstore: store: inmemory schema_config: configs: - from: 2024-01-01 store: tsdb object_store: filesystem schema: v13 index: prefix: index_ period: 24h limits_config: retention_period: 720h allow_structured_metadata: false compactor: working_directory: /loki/compactor retention_enabled: true delete_request_store: filesystem analytics: reporting_enabled: false YAML

7. Buat Alloy Config

File config.alloy lengkap

Konfigurasi ini membaca Laravel log, menangani multiline stack trace, memberi label env/level, lalu mengirimnya ke Loki. NPM access/error log juga ikut dikirim.

cat > /opt/stacks/observability/alloy/config.alloy <<'ALLOY' local.file_match "foodlab_laravel_logs" { path_targets = [ { "__path__" = "/logs/foodlab/laravel/*.log", "job" = "foodlab-laravel", "app" = "foodlab", "service" = "laravel", "server" = "singapore", }, ] sync_period = "5s" } loki.source.file "foodlab_laravel" { targets = local.file_match.foodlab_laravel_logs.targets tail_from_end = false forward_to = [loki.process.foodlab_laravel.receiver] } loki.process "foodlab_laravel" { stage.multiline { firstline = "^\\[[0-9]{4}-[0-9]{2}-[0-9]{2} [0-9]{2}:[0-9]{2}:[0-9]{2}\\]" max_wait_time = "3s" } stage.regex { expression = "^\\[(?P<timestamp>[^\\]]+)\\] (?P<laravel_env>[^.]+)\\.(?P<level>[A-Z]+):" } stage.labels { values = { laravel_env = "laravel_env", level = "level", } } forward_to = [loki.write.local.receiver] } local.file_match "npm_logs" { path_targets = [ { "__path__" = "/logs/npm/*access.log", "job" = "nginx-proxy-manager", "app" = "npm", "service" = "nginx-proxy-manager", "type" = "access", "server" = "singapore", }, { "__path__" = "/logs/npm/*error.log", "job" = "nginx-proxy-manager", "app" = "npm", "service" = "nginx-proxy-manager", "type" = "error", "server" = "singapore", }, ] sync_period = "5s" } loki.source.file "npm" { targets = local.file_match.npm_logs.targets tail_from_end = false forward_to = [loki.write.local.receiver] } loki.write "local" { endpoint { url = "http://monitoring-loki:3100/loki/api/v1/push" } } ALLOY

Validasi akhir file:

tail -n 30 /opt/stacks/observability/alloy/config.alloy

Akhir file harus seperti ini:

loki.write "local" { endpoint { url = "http://monitoring-loki:3100/loki/api/v1/push" } }

8. Start Observability

Jalankan Loki dan Alloy

cd /opt/stacks/observability docker compose up -d docker compose ps

Sekarang tidak boleh ada error:

network monitoring declared as external, but could not be found

Kalau masih muncul, cek lagi network monitoring:

docker network ls | grep monitoring

9. Test Loki dan Alloy

Readiness dan log container

curl http://127.0.0.1:3100/ready docker logs --tail=120 monitoring-loki docker logs --tail=120 monitoring-alloy

Cek dari Grafana ke Loki:

docker exec -it monitoring-grafana wget -qO- http://monitoring-loki:3100/ready

10. Tambahkan Grafana ke NPM

Proxy Host Grafana

Di Nginx Proxy Manager, buka Proxy Hosts -> Add Proxy Host, lalu isi:

Domain Names: grafana.foodlabpens.com www.grafana.foodlabpens.com Scheme: HTTP Forward Hostname / IP: monitoring-grafana Forward Port: 3000 Block Common Exploits: ON Websockets Support: ON

Tab SSL:

SSL Certificate: Request a new certificate Force SSL: ON HTTP/2 Support: ON Klik Save

11. Generate Test Log FoodLab

Kirim log manual ke Laravel log

printf "[%s] production.ERROR: Loki test from Foodlab server baru {\"source\":\"manual-test\"}\n" "$(date '+%Y-%m-%d %H:%M:%S')" | sudo tee -a /opt/stacks/foodlab/src/storage/logs/laravel.log > /dev/null

Tunggu sekitar 10 detik, lalu query Loki:

curl -G -s "http://127.0.0.1:3100/loki/api/v1/query" \ --data-urlencode 'query={app="foodlab"}' | head -c 1500

Kalau masuk, cek di Grafana Explore menggunakan datasource Loki:

{app="foodlab"}

Error Laravel:

{app="foodlab", level="ERROR"}

NPM logs:

{app="npm"}

12. Final Container Check

Cek container dan network

docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"

Harus ada container:

monitoring-prometheus monitoring-grafana monitoring-node-exporter monitoring-cadvisor monitoring-loki monitoring-alloy

Network monitoring harus memperlihatkan semua container ini:

docker network inspect monitoring | grep -E '"Name"|monitoring-prometheus|monitoring-grafana|monitoring-node-exporter|monitoring-cadvisor|monitoring-loki|monitoring-alloy'
